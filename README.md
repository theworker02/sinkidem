# sinkidem

Sink validation gates for idem inputs before they hit prod.

**Site:** https://theworker02.github.io/sinkidem/

## Install / run

```bash
git clone https://github.com/theworker02/sinkidem.git
cd sinkidem
node src/cli.js
node --test
```
